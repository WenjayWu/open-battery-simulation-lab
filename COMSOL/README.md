# COMSOL Integration Area

此目录是公开仓库与 COMSOL 之间的说明和自动化接口，不是 COMSOL 软件安装目录。

可以保存：英文命名的说明、可公开的 Java/MATLAB/命令行脚本、小型文本配置、模型索引和可重建步骤。

不得保存：软件本体、安装器、ISO、压缩包、补丁、许可证文件、密钥、`*.mph`、`*.mphbin`、恢复文件、大型求解结果或未获许可公开的模型。

COMSOL 软件使用系统标准安装位置；私人二进制模型放在仓库外的受控数据目录并独立备份。若需要公开工作流，优先提交参数说明、脚本化重建步骤或经过筛选的小型交换格式。具体规则见 [`docs/MAINTENANCE_GUIDE.md`](../docs/MAINTENANCE_GUIDE.md)。
