# 已验证参考摘要

这里仅保存体积很小的验收摘要和代表性图片，不保存求解器原始大输出。完整运行包默认写入 `results/runs/` 并被 Git 忽略。

- `baseline_summary.csv`：Prada2013、25°C、95% 初始 SOC 的完整 DFN 基线。
- `sei_plating_demo_summary.csv`：混合参数方法示例；必须与 `illustrative_unvalidated` 标签一起解读。
- `verification.json`：运行时版本、配置哈希和重复性结果。
- 两张 PNG：对应基线总览与带水印的退化信号图。

数值仅用于验证软件管线可重复，不是对实验电芯的校准结论。
